# «Сегодня» и дата задачи — решения

Грилинг с владельцем 25–26.11.2026, итог подтверждён. Это решения, а не
контракт API: контракт и макеты пишутся перед реализацией, на основе этого
файла. Продолжение `design/goals-ideas-contract.md`.

## Проблема

Мелкие дела на день — ответить человеку, пятиминутный созвон, админка —
теряются в общем списке и живут только в голове. Владелец перепробовал три
пути, и все плохи:

- **Напоминания по времени.** Расписание разъезжается: одни дела занимают
  5 минут вместо часа, другие наоборот. В итоге пуши сыплются кучей или
  остаются дыры.
- **Рабочий набор.** В нём смешаны работа и дом. Если взять лишнего, набор
  копится снежным комом, его перестают смотреть, и он становится мусором.
- **Держать в голове.** Общей картины нет.

Цикл владельца, на который всё ложится: пул → отбор приоритетов → пул скрыт →
задачи по одной → пул снова открыт. В этот цикл входит и просмотр сделанного
ради продолжений («зарелизил — через неделю собрать отзывы»).

## Решения

1. **Дата задачи** — «когда этим заняться», а не только напоминание. Это
   расширение нынешнего `remindAt`.
   - Время необязательно и ставится только там, где важен момент («встретить
     курьера в 15:00»). Пуш приходит только у задач со временем.
   - У задач с одной датой пушей нет, утреннего пуша тоже нет.
   - Дедлайна нет: «к пятнице» выражается датой.
2. **«Сегодня»** — компактный блок в режиме «Работа».
   - Не занимает рабочий набор.
   - Не скрывает пул: пул по-прежнему открывается, когда рабочий набор пуст.
   - Не вызывает дуэль.
   - Внутри подзаголовки по скоупам («Работа», «Дом»).
3. **Как задача попадает в «Сегодня»:**
   - сама, когда наступила её дата;
   - из стопки кнопками «Сегодня» и «Завтра»;
   - диктовкой («…сегодня», «в четверг»).

   Все три способа пишут одно и то же поле.
4. **Несделанное само на следующий день не переезжает.** На следующий день
   задача уходит из «Сегодня» в секцию **«С прошлых дней»** над списком дня.
   - Действия: в сегодня / на другую дату / в стопку (снять дату), плюс общая
     кнопка «Все в сегодня».
   - Неразобранное остаётся в секции, пока его не разберут.
   - Отдельного экрана «спланировать день» нет: секция сама видна при первом
     открытии «Работы» за день.
   - *Отложено:* если не приживётся — приложение требует разобрать хвост,
     прежде чем пускать дальше.
5. **Сделанное за день** остаётся в списке зачёркнутым и уходит вниз до конца
   дня. Сверху счётчик «4 из 7». Наутро сделанное исчезает.
6. **Заблокированная задача с датой** — дата значит «когда проверить». В свой
   день задача появляется в «Сегодня» с замком. Действия: «разблокировать»
   (становится обычной задачей на сегодня) или «ещё ждём → дата».
7. **Виджет** показывает строку «Сегодня 3 из 7» и ближайшую задачу со
   временем. Тап открывает «Работу».
8. **«Следом…»** — необязательная кнопка, которая ненадолго появляется при
   отметке «сделано». Создаёт продолжение в том же проекте с датой.
   Просмотр сделанного разбирается в теме истории.
9. **Далёкие задачи.** Задача с датой дальше **горизонта** сворачивается
   внизу проекта в строку «Позже: N · ближайшая 25 фев». Заблокированные
   сворачиваются по тому же правилу. Горизонт — общая настройка для всех
   проектов, по умолчанию **10 дней**. В свой день задача появляется в
   «Сегодня».
10. **Миграция.** Старые напоминания становятся датами. Задачи с прошедшей
    датой (на 26.11 их 14) в первый день попадут в «С прошлых дней» — это
    будет первая живая проверка секции. Время у будущих задач сохраняется.
11. **MCP.** Дата и время видны агентам. Агенты ставят их только по просьбе
    владельца: они ничего не создают и не планируют в TaskRadar без спроса
    (см. `agent-skill/taskradar/SKILL.md`).

## Не решено здесь

- История, ритм проекта и ритуал пересмотра, включая просмотр сделанного, —
  следующая тема обсуждения.
