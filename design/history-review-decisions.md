# История, пересмотр и ритм — решения

Грилинг с владельцем 27.11.2026, итог подтверждён. Реализуется вместе с
`design/today-decisions.md`. Контракт API — `design/today-history-contract.md`.

## Зачем История

Задача «История задач не отвечает на вопрос, ради которого была сделана».
Теперь История отвечает на два вопроса:

- **«Куда ушла неделя?»** — что реально сделано, и сравнение с тем, что собирался.
- **«Что следует из сделанного?»** — просмотр закрытого ради продолжений:
  «зарелизил → через неделю собрать отзывы».

На «что гниёт» отвечают «С прошлых дней», «Позже» и пересмотр.
На «двигаюсь ли в важном» — цели.

## Решения

1. **Экран «История»** открывается списком **«Сделано»**.
   - Свежие задачи сверху, группы по дням («Сегодня», «Вчера», «пн 24.11»);
     у каждой задачи время закрытия и проект.
   - Действия у задачи: **«Вернуть»** (случайно закрытая) и **«Следом…»**.
   - Карточка пересмотра стоит сверху, только когда пересмотр пора делать.
   - Вторая вкладка **«Недели»**: «путемер» — записи пересмотров с недельными
     столбиками закрытого и итоговой строкой, плюс достигнутые цели.
   - График «что висит дольше всего» убирается, дневной график заменяют
     недельные столбики.
2. **«Вернуть»**.
   - Задача возвращается в прежний статус и на своё место в проекте.
   - Если была в рабочем наборе — возвращается в него.
   - Если её дата — сегодня, она снова в «Сегодня».
   - В журнал пишется событие «возвращена».
   - Закрытие больше не считается ни в «Сделано», ни в счётчиках недели.
3. **Пересмотр — раз в неделю.**
   - День и время настраиваются, по умолчанию понедельник утром.
   - Один пуш. Если пересмотр пропущен — метка на вкладке «История», без
     повторных напоминаний.
   - Следующий пересмотр охватывает всё время с прошлого.
   - Один пересмотр на все контуры, внутри — разделы по контурам.
   - Месячный пересмотр — это первый пересмотр нового месяца с разделом
     «за месяц»: закрыто по проектам и достигнутые цели.
4. **Шаги пересмотра.** Каждый можно пропустить; уточним по реальным данным.
   1. **Сделано** с прошлого пересмотра, по проектам → «Следом…» у каждой
      задачи.
   2. **Задумано, но не сделано** → оставить / в стопку / снять.
   3. **Цели**: окна → оставить / уступить / достигнута; пустой слот можно
      занять со скамейки.
   4. **Ритм**: проекты с тишиной или перебором → взять задачу в набор /
      почистить / поменять норму.
   5. **Неделя вперёд**: рабочий набор и даты.
   6. **Итог** одной строкой, необязательно.
5. **«Собирался»** = рабочий набор на момент пересмотра + шаги целей в слотах
   + задачи с датами на прошедший период. Отдельного «плана недели» нет.
6. **Запись пересмотра**: дата, период, числа (закрыто всего и по проектам,
   достигнутые цели) и итоговая строка. «Путемер» — это ряд таких записей.
7. **Ритм проекта** включается только по выбору, в настройках проекта. Два
   необязательных числа:
   - норма «≥ N закрытых в неделю», которая сравнивается со средним за
     последние 2 недели;
   - потолок «≤ M открытых».

   Считается только количество, размеров у задач нет. В планировании у проекта
   приглушённая метка («тишина 3 нед», «перебор 24/20»), без красного и без
   пушей. Решения по ритму принимаются на пересмотре.
