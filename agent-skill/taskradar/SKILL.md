# TaskRadar

TaskRadar — личный трекер владельца. Доступ к нему — MCP-сервер `taskradar` (user-скоуп, есть в каждом проекте).
Инструменты: `list_projects`, `list_tasks`, `get_task`, `get_picture`, `list_notes`, `list_inbox`, `search`, `create_task`, `update_task`, `move_task`.

Этот skill лежит в репозитории TaskRadar (`agent-skill/taskradar/`) и подключён в `~/.claude/skills` ссылкой (`scripts/install-agent-skill.ps1`). Меняешь инструменты MCP — поправь и этот файл.

## Если инструментов `mcp__taskradar__*` нет в сессии

Сначала `ToolSearch` с запросом `+taskradar` — сервер мог ещё подключаться.
Если не нашлось — тот же сервер через запасной клиент рядом с этим файлом (токен он берёт из `~/.claude.json` сам, не выводи его):

```bash
python -I -X utf8 ~/.claude/skills/taskradar/mcp_call.py tools
python -I -X utf8 ~/.claude/skills/taskradar/mcp_call.py list_tasks '{"status":["pending","blocked"]}'
python -I -X utf8 ~/.claude/skills/taskradar/mcp_call.py get_task '{"taskId":"..."}' --images DIR
```

С `--images DIR` картинки из ответа сохраняются в DIR файлами — открой их через Read. Скажи владельцу одной строкой, что MCP в сессии не поднялся и ты пошёл через запасной клиент.

## Как отвечать

- Статусы: `pending` — в работе, `blocked` — заблокирована, `done` — сделана. «Что в работе / мои задачи» = `pending` + `blocked`. `inWorkingSet` — задачи, которые владелец отобрал «делать сейчас».
- `list_tasks` отдаёт `projectId`, не имя — имена бери из `list_projects` (там же скоупы: «Основной», «Мои проекты», «Работа»).
- Группируй по скоупу → проекту, в порядке выдачи (это приоритет владельца). `current: true` — текущая задача проекта, помечай ★. В списке `pictures: N` — у задачи есть картинки, `checklist: {done,total}` — прогресс чек-листа.
- Если владелец в репозитории, который совпадает с проектом TaskRadar по имени (папка `CashFlow` → проект CashFlow), и спросил «мои задачи» без уточнения — покажи сначала задачи этого проекта, затем предложи остальные.
- Берёшься за задачу — сначала `get_task`: полный текст, чек-лист, журнал и картинки (обычно скриншоты бага — смотри их). Первые 5 картинок приходят в ответе, остальные — `get_picture` по id.

## Изменения

- `create_task`, `update_task`, `move_task` меняют данные владельца: делай их, когда он об этом попросил, или подтверди одной фразой, если инициатива твоя (например, follow-up по итогам работы).
- Закрытие — `update_task` со `status: "done"` (пишется в журнал, задача выходит из рабочего набора). Рабочий набор — `update_task` с `inWorkingSet`.
- Чек-лист в `update_task` передаётся целиком: сохраняй `id` пунктов из `get_task`, у новых пунктов `id` не нужен.
- Удаления через MCP нет — не обходить.
